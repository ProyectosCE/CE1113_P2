### Objetivo

Mediante el desarrollo de este proyecto el estudiante aplicará los conceptos de diseño a nivel de sistema (System Level Design) y co-diseño hardware/software mediante el modelado, análisis de trade-offs y implementación de un sistema en chip (SoC) para un reproductor de audio portable avanzado.

Al finalizar este proyecto, el estudiante habrá puesto en práctica metodologı́as modernas de diseño de sistemas embebidos, incluyendo la toma de decisiones arquitecturales sobre la partición hardware/software, ası́ como aplicado técnicas de programación de bajo nivel Bare Metal y diseño de hardware personalizado.
